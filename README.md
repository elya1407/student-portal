# Student Portal 603-41

Студенческий портал для группы **603-41**: регистрация студентов, личный кабинет, расписание по подгруппам, отметка посещаемости, объявления, админка старосты, Excel-экспорт и REST API под будущего Telegram-бота.

## Стек

- Java 17
- Spring Boot 3
- Spring Security
- Spring Data JPA
- Thymeleaf
- Bootstrap 5
- H2 для локальной разработки
- PostgreSQL для реального размещения
- Apache POI для Excel

## Быстрый запуск

1. Установить Java 17 и Maven.
2. Скачать проект или клонировать репозиторий.
3. В папке проекта выполнить:

```bash
mvn spring-boot:run
```

4. Открыть сайт:

```text
http://localhost:8080
```

По умолчанию используется H2 в памяти. База создаётся автоматически через `schema.sql`, данные загружаются через `data.sql`.

## Вход старосты

```text
Админка: http://localhost:8080/admin/login
Логин: starosta
Пароль: starosta60341!
```

Пароль хранится в БД как BCrypt-хэш.

## Регистрация студентов

SMS нет, всё бесплатно. Логика такая:

1. Студент выбирает «Регистрация».
2. Вводит ФИО точно как в списке.
3. Вводит свой номер зачётки из таблицы ниже.
4. Указывает телефон, email, дату рождения и придумывает пароль.
5. После регистрации входит по номеру зачётки и паролю.

ФИО и номер зачётки после регистрации студент сам менять не может. Это делает староста в админке.

## Как работает отметка

- У каждого студента есть подгруппа.
- Расписание загружено в таблицу `schedule`.
- Неделя считается автоматически:
  - нечётная ISO-неделя = `числитель`;
  - чётная ISO-неделя = `знаменатель`.
- Кнопка «Я на паре» активна:
  - 15 минут с начала пары по расписанию;
  - или 15 минут после ручного открытия отметки старостой.
- По текущему ТЗ стоит ограничение: **1 отметка в день на студента**.

Если позже нужно отмечать каждую пару отдельно, нужно добавить в `attendance` поле `schedule_id` и заменить уникальность `student_id + date` на `student_id + date + schedule_id`.

## REST API для будущего Telegram-бота

API уже вынесено отдельно и работает через те же сервисы, что и сайт.

Ключ задаётся в `application.properties`:

```properties
app.bot-api-key=dev-bot-key-change-me
```

Бот должен передавать ключ в заголовке:

```text
X-BOT-API-KEY: dev-bot-key-change-me
```

### Эндпоинты

```http
GET /api/student/{recordBook}
GET /api/schedule/today?recordBook=603410101
POST /api/attendance/mark
GET /api/attendance/history?recordBook=603410101
```

Пример отметки через API:

```bash
curl -X POST http://localhost:8080/api/attendance/mark \
  -H "Content-Type: application/json" \
  -H "X-BOT-API-KEY: dev-bot-key-change-me" \
  -d '{"recordBookNumber":"603410101"}'
```

## PostgreSQL

1. Создать базу:

```sql
CREATE DATABASE student_portal_60341;
```

2. В `src/main/resources/application-postgres.properties` поменять логин и пароль PostgreSQL.
3. Запустить:

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=postgres
```

Важно: сейчас `schema.sql` каждый запуск пересоздаёт таблицы, чтобы проект стартовал «с нуля». Для реального использования после первого запуска лучше поставить:

```properties
spring.sql.init.mode=never
```

или перейти на Flyway/Liquibase.
